# Ship the slice, name the ideal

1. Present the ideal and the shippable slice side by side.
2. Park what's left explicitly, with where it is tracked.
3. Never defer security or identity to a later slice.
4. When unsure, keep options open: choose the option with the fewest one-way doors, and name each door.
5. Tensions: rigour where users are live and on identity and security, speed on pre-launch work; the
   ideal for greenfield, a direct cutover over a long strangler where it's safe.
