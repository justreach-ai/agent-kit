# Critical thinking

1. State the question narrowly enough that its answer changes a decision. Name the action that hangs on it.
2. Separate the observation from its interpretation. Check what the measurement includes, its time
   window and its source. Two reports copied from the same counter are one observation.
3. Where different explanations still fit, say what each predicts about the same case. Choose a
   check whose possible results would lead you in different directions. Use the cheapest permitted
   source that can answer it.
4. Report what you found, which explanation it supports, and what to do on that evidence. If the check
   is unavailable or inconclusive, say what remains open and whether the decision can safely proceed.

**Example.** A dashboard shows a drop in completed forms after a new layout shipped. Before rolling
it back, compare saved submissions with dashboard events over the same period. Steady saves with
fewer events points to measurement. If saves also fell, check starts and failures by layout version
before attributing the drop to the design.
