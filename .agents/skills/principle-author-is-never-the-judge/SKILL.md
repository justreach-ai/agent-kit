# The author is never the judge

1. Never review work you wrote in this context. Hand it to a reviewer agent that can read but not edit.
2. For high stakes, use at most two reviewers, split by risk (for example security and data), not more.
3. Give the reviewer the material, not your conclusion: an agent handed a hypothesis tends to confirm it.
4. Summaries, PR bodies, earlier reviews, bot findings and green CI are claims to check, not evidence.

Why: the author's context holds the same blind spots that produced the fault.
