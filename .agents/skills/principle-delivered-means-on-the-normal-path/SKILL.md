# Delivered means on the normal path

1. A side demo, a lab, or work merged but inactive when it was meant to be active is not delivered.
2. A feature behind a flag on purpose, for a staged rollout with a named gate, is delivered to that flag's
   audience: say which.
3. Show it working in the real app or the staging flow.
