# Fix the limit, don't pause

1. If your approach is slow, flaky or capped, improve the approach; don't quietly drop the capability.
2. If it is disturbing something people are using, stop the disturbance first, then fix it.
3. A gate, a refused permission, a quota or a guardrail someone else set is not a limit to remove.

Why: switching a capability off hides the problem and leaves the work worse than it was asked for.
